# 路线中无法取得的金币和药水

当前路线会给所有普通战加11金币、精英加30金币，并将这些金币计入后续商店预算；还给普通战/精英的预期新药水0.4/0.52份价值。持有灵体外质（ECTOPLASM）或添竹（SOZU）时，这些收益不可取得，导致战斗与后续商店路线被高估。

基于master `be5fc24b69ec84748c74b003be5a29ec3246b0b7`，新增默认关闭参数 `route_forbidden_reward_gains=false`，幕范围 `[2]`。启用后只根据玩家当前公开遗物计算：ECTOPLASM使预期新金币为0，SOZU使预期新药水为0。普通战、精英与问号的怪物分支适用；金币增加为0还会限制后续商店的预计购买力。已有金币、已有药水及其原风险缓冲保留，卡牌/遗物奖励、商店/事件其他收益保持原模型。两种限制可叠加。

机制源码：v0.111.0 `Ectoplasm.cs:18–24` 的 `ModifyGoldGained` 返回0；`PlayerCmd.cs:144` 在实际加金币前执行该钩子。`Sozu.cs:17–19` 对持有者拒绝 `ShouldProcurePotion`；`PotionCmd.cs:31` 先执行钩子，不允许则失败返回。无需读取真实随机数、隐藏牌序、私有状态或未来库存。

旧新100局有5局持有这两件遗物，公开选牌快照证据29个（灵体外质12、添竹17）；旧开发60局没有覆盖，建议主线以新种子组配对，另按真实持有/触发局报告。不能把5局或29快照当作已发生收益。社区过滤后赢家和输家持灵体外质房间均记录0新金币，持添竹房间均记录0成功获得药水；灵体外质持有者仍能花已有的钱、拿药，添竹持有者仍能拿金币，不能全面清零资源。

验证：6项新检查，19项既有路线检查，总25项通过；原生进程被测试阻断，正常局/模型/远端任务新增0。预期仅减少已持有遗物时的虚假战斗资源收益和商店购买力；仍沿用原损耗近似，未验证更高胜率。正向能量收益、遗物的其他代价、未来取得/移除遗物、未知事件具体收益均未由本项建模。需主线单开参数，记录路线变化、A2/A3/full和全部死亡/错误。
