# 输出核心研究（铁甲战士 · A10 · 测试版 v0.111.0）

2026-10-03。起因：复盘两局发现我们的牌组**没有输出核心**（没有能赢下长战斗的伤害引擎）、**也没有配合**，所以第二幕普通战掉血是人类赢家的 2~3 倍、第二幕 Boss 输 60~87%。
这份文档用数据回答：赢家的核心有哪几种、什么时候拿、拿了以后补什么、我们缺什么、能写成什么规则。

- 数据：社区对局 9761 局（赢 1999）；高手 5 人 193 局（胜率 76%，只用哈希，不含任何玩家名）；逐事件录像 v0.111.0 干净的 716 局；我们的 200 局（`results/v16h-hp80.jsonl`、`fresh300-hp80.jsonl`）。
- 复现：`bash docs/scripts/run_all.sh`（单进程，机器忙时约 20 分钟），每个脚本的完整输出在 `docs/scripts/out/`。各节末尾写了出处。
- 口径：全部是**关联**。为了压住幸存者偏差，比较都放在「走到同一个检查点的局」里，并用逻辑回归控制精英数、遗物数、升级数、牌组张数、进场血量（第二幕 Boss 再加 Boss 是谁），表里的「调整」就是这个。
- 和已有研究的关系：方向和 `research/玩家对局规律-20261002.md` 规律 5、8，`ironclad/16`、`17` 号一致；本文新增的是调整后的效应、按阶段的拿牌后果、成型时间、凑齐概率、分 Boss 的差别、我们的牌组对照和掉血分解，以及可以直接写进程序的数字。有两处修正见第七节。

## 零、结论（先看这一节）

1. **数据里真正算「核心」的只有两种：消耗引擎、格挡转伤害。** 另有一组「周转」牌（祭品、战斗专注、放血、被遗忘的仪式、薪火之源）和凶恶，对第二幕 Boss 帮助很大，但它们算辅助，本身不构成核心。
   - 消耗引擎 = 无惧疼痛 / 黑暗之拥 + 至少 2 种主动消耗牌（燃烧契约、坚毅、重振精神、添柴、恶魔之焰、破灭……）。
   - 格挡转伤害 = 全身撞击 + 壁垒 / 坚定不移 / 势不可当 / 无惧疼痛；或 势不可当 + 一个持续格挡来源。
   - 第一幕结束时有其中之一：最终通关 **+11.0 个百分点**（调整后，z=5.1，530 局），过第二幕 +6.4；第二幕 Boss 前有：最终通关 **+15.6**（z=8.5，1109 局）。
   - 力量多段、自伤（狱火 / 撕裂）、易伤（残酷 / 欺凌）、打击（完美打击 / 地狱狂徒）这四种「看起来像输出核心」的组合，调整后都不加分；打击流明显减分（第二幕 Boss 前有它，最终通关 −10.9）。**只有这四种、没有前两种**的牌组，第一幕结束时最终通关 −6.5（z=−4.7）。
2. **这两种核心本质上不是「伤害引擎」，而是「一台机器」**：把烧牌变成格挡和抽牌，把格挡变成伤害，每回合挡得住、牌转得动。录像里赢家的伤害很分散：第二、三幕 Boss 战，伤害最多的牌最常见的是全身撞击、打击、灰烬打击（各占 7~8% 的场次），没有哪一张牌包办输出。
   兑现牌单独看几乎不加分：已有消耗引擎时，再有灰烬打击、契约终结，胜率不比只有引擎更高（2.5 节）。**值钱的是引擎本身，不是终端。**
3. **核心在第一幕后半到第二幕前半凑齐**（中位全局第 19~21 层，第一幕 Boss 在第 17 层）。第一幕结束时 0 个零件的局，到第二幕 Boss 只有 3% 能凑齐；有 2 个零件的是 32%。第二幕第 9 个节点还没核心，之后只有 8% 能凑齐。
   **第一幕 Boss 的稀有牌奖励是关键的一次**：黑暗之拥、添柴、壁垒、坚定不移、祭品，29~35% 是从这里拿到的。
4. **按阶段拿**：第一幕前半（第 1~9 层），拿引擎零件反而让过第一幕的概率变低（无惧疼痛 −7、全身撞击 −12、战鼓 −16 个百分点），这时候过渡攻击是对的（战斗专注 +14、重锤 +11、无情猛攻 +10、与我一战！+9）。
   从**第一幕后半**起反过来：引擎零件拿了好（重振精神：过第二幕 +14、通关 +19），过渡攻击变成负的；到**第二幕**，攻击牌普遍是大负数（暴走 −22、预备打击 −20、惊逃 −17、燃烧 −15、突破 −13 个百分点的通关率）。
5. **我们的牌组**：死在第二幕的 111 局里只有 **8%** 有核心（人类死在第二幕的 18%，人类赢家第二幕 Boss 前 31%，高手 36%）。
   我们拿了一堆独立攻击牌：愤怒 60%（人类赢家 24%）、突破 41%（20%）、双重打击 32%（13%）、暴走 17%（4%）、飞剑回旋镖、地狱之刃、惊逃、燃烧、预备打击……
   缺的是：无惧疼痛 13%（32%）、重振精神 10%（27%）、燃烧契约 13%（29%）、放血 17%（35%）、坚定不移 2%（17%）、凶恶 4%（19%）、耸肩无视 32%（52%）、全身撞击 5%（16%）、添柴 5%（16%）。
6. **但「缺核心」只是第二幕多掉血的一部分原因。** 用人类数据拟合「牌组 → 每场掉血」：我们第二幕普通战实际比人类赢家多掉 12.6 血/场，其中牌组能解释 6.9（牌本身只有 1.0，遗物少、升级少占 5.9）；精英多掉 17.9，牌组解释 10.6；Boss 多掉 26.9，牌组解释 8.6。
   **一半以上的差距不在牌组里**（打法、药水、路线等）。只改选牌，第二幕不会一下子变好；精英打得少造成的遗物差距，和选牌一样重要。
7. **为什么我们拿不到核心（推测，未验证）**：程序的选牌模型（学自赢家）在第二幕本来就偏好引擎牌（例：第二幕愤怒 −1.5、暴走 −2.4，无惧疼痛 +0.5、祭品 +2.4），但选牌时开着「模拟实打」（`simeval_pick`：分数 = 模拟少掉的血 ÷ 5 + 0.5 × 模型分），模拟只打本幕 / 下一幕的 Boss 和精英，**看得见攻击牌马上多打的伤害，看不见引擎在之后十几场战斗里的回报**。v17a 把研究规则放进模型分（又被 ×0.5）后效果变差，也说明规则要分阶段、加在模拟之后。

### 最重要的三条规则（详细数字见第五节）

1. **分阶段**：第一幕前半不追核心（过渡攻击照拿）；从第一幕第 10 层（含第一幕 Boss 奖励）起，还没有核心时给引擎零件加分（+0.3~0.7）；**能立刻凑齐核心的牌再加 +0.6~1.0**。
2. **有了核心就换选牌口味**：有消耗引擎 → 战鼓 +1.3、黑暗之拥 +0.9、无惧疼痛 / 灰烬打击 / 势不可当 +0.7；有格挡转伤害 → 壁垒 +1.3、全身撞击 +1.2。同时**独立攻击牌降到 −1.5~−2**（拆卸、完美打击、狱火、重锤、暴走、愤怒、突破、预备打击……）。
3. **第二幕起，没有核心也不拿独立攻击牌**（暴走 −1.4、预备打击 −1.1、完美打击 / 地狱狂徒 / 御血术 / 踩踏 −0.8、惊逃 / 突破 / 燃烧 / 愤怒 / 与我一战！−0.6~−0.7），没有合适的就跳过；第二幕第 9 个节点后还没核心，转去拿对付本幕 Boss 的牌（无惧疼痛、坚定不移、凶恶、周转牌、恶魔形态）。

分数单位 = 选牌模型的 logit（和 `buildrules.card_bonus` 同一个单位）。开着 `simeval_pick` 时先验会再乘 0.5，所以**这些分建议加在模拟之后**（见 5.0）。

### 1.4 每场战斗少掉多少血（主要症状）

每场战斗取进场时的牌组，线性回归控制遭遇是谁、本幕第几个节点、遗物数、升级数、张数、最大生命。**「消耗或格挡核心」的系数**（负数 = 少掉血；±是 95% 区间）：

| | 普通战 | 精英 | Boss |
|---|---|---|---|
| 第一幕 | +0.8（±0.6） | +0.6（±1.2） | −3.6（±1.5） |
| 第二幕 | **−1.1（±0.4）**，22081 场 | **−1.9（±0.7）**，10933 场 | **−4.7（±1.3）**，4470 场 |
| 第三幕 | −1.5（±0.4） | −3.8（±0.9） | **−7.7（±1.2）** |

- 第二幕普通战平均每场掉 12.1（最终赢家 8.9、输家 13.9）：核心能解释赢家和输家差距里的一部分，不是全部。
- 自伤核心在第二、三幕每场**多掉** 2.0~3.3 血；打击核心在第二、三幕 Boss 多掉 2.8~4.4。
- 核心的回报越往后越大（第三幕 Boss −7.7），所以第一幕前半不值得为它牺牲过关率（见第二节）。

### 1.5 录像：输出从哪里来

716 局干净录像（v0.111.0），每一下伤害按打出它的牌归属（`replay_damage.py`）：
- 赢家第二、三幕 Boss 战每场输出 823，输家 510；普通战 219 / 166。赢家每场多打出约 30~60%。
- **伤害很分散**：第二、三幕 Boss 战，伤害第一的牌，赢家里是全身撞击 8%、打击 8%、灰烬打击 7%、痛殴 5%、焚烧 4%、欺凌 4% 的场次……没有哪一张牌包办。输家伤害第一的牌更常是打击（10%）、完美打击（7%）、暴走（4%）、熔融之拳（4%）。
- 「出场就挑大梁」的牌（出场时平均占这场伤害的比例，赢家）：旋风斩 30%、势不可当 28%、完美打击 27%、重锤 27%、彼岸咆哮 27%、焚烧 26%、全身撞击 23%、恶魔之焰 23%、灰烬打击 22%、痛殴 21%。但输家里这些牌的占比也差不多，**说明大伤害牌人人会用，差别在于赢家同时挡得住、转得动**（和规律 10「赢家挡满率 45~51%，输家 25~35%」一致）。
- 注：少数录像里出现别的角色的牌（小刀、午夜等，来自事件），不影响上面的结论。

## 二、什么时候拿、拿了以后补什么（问题 2）

### 2.1 核心在什么时候凑齐

（第二幕 Boss 前已有核心的局；第一幕 = 全局第 1~17 层，第 17 层是 Boss；第二幕 = 18~33 层；「前半」= 本幕第 0~8 个节点）

## 五、可以直接写进程序的规则（问题 5）

### 5.0 单位和接法

- 下面所有分都是**选牌模型的 logit 单位**（和 `policy/buildrules.py` 的 `card_bonus` 一样：+1 ≈ 这张牌被选中的几率比（odds）×2.7）。
  数字大多直接取自人类的拿取率差（Δlogit），所以「加了这么多分 ≈ 像人类赢家那样看重它」。
- `rewards.choose` 开着 `simeval_pick` 时：最终分 = 模拟分 ÷ 5 + **0.5** × 模型分。规则放在模型分里会被打对折，而模拟只看本幕 / 下一幕的 Boss 和精英、看不到引擎的长期回报。
  **建议：新加一个 `core_bonus(card, deck, act, node_idx, boss)`，在模拟之后单独加，系数 `core_w`**；A/B 测 `core_w` = 0.5 / 1 / 2 三档，和对照比同一批种子的「过第一幕 / 过第二幕 / 第二幕每场掉血」。
- v17a（研究规则 1.0 权重、全阶段生效）让过第一幕从 70% 降到 64%。下面的规则**第一幕前半基本不动**，就是为了避开这个坑。

  - **帝皇蟹**：无惧疼痛 +0.7、坚定不移 +0.7、凶恶（易伤来源 ≥2）+0.5；商店删牌优先基础打击（≥4 张时过关 −8.9）。
  - **知识恶魔**：恶魔形态 +0.5、坚定不移 +0.4、周转牌（TEMPO，已有 <2 种时）+0.4。
  - **无厌沙虫**：凶恶 +0.5、恶魔形态 +0.4、周转牌 +0.4。
  - 这几个数是把「过 Boss 概率 +7~14 个百分点」按和规则 2 同量级折算的【推测】，要靠 A/B 定。

**规则 6 · 第二幕跳过**：有核心后，奖励里没有 IF_EXH / IF_BLK 里的正分牌，且三张都在规则 4 名单里 → 跳过（人类赢家第二幕跳过约 39%，17 号 7.4）。

### 5.3 优先顺序（还没核心时，第一幕后半到第二幕）

1. 能立刻凑齐核心的牌（规则 1 + 规则 2）：无惧疼痛 / 黑暗之拥（已有 ≥2 种主动消耗）、第二种主动消耗（已有引擎）、全身撞击（已有壁垒 / 坚定不移 / 势不可当 / 无惧疼痛）、壁垒 / 坚定不移（已有全身撞击）。
2. 引擎：无惧疼痛、黑暗之拥、添柴（+0.65~0.7）。
3. 主动消耗：燃烧契约、重振精神、恶魔之焰、破灭（+0.35~0.65）。
4. 周转：战斗专注、祭品、放血、被遗忘的仪式；凶恶（有易伤来源时）。
5. 第一幕：过渡攻击（A1a 正分）；第二幕：跳过。

有核心以后：IF_EXH / IF_BLK 的正分牌 > 周转 > 跳过；独立攻击牌基本不拿。

### 5.4 检查点（可做成日志里的诊断，先不改决策）

- 第一幕 Boss 前：零件种类 ≥2？（0 个 → 第二幕 Boss 前只有 3% 能凑齐）
- 第一幕 Boss 奖励：有稀有引擎牌（黑暗之拥、添柴、壁垒、坚定不移、祭品、恶魔之焰）时优先。
- 第二幕第 9 个节点：有没有核心？没有 → 切到规则 5。
- 每局结束记录：死时有没有核心、零件数、规则 4 名单里的牌拿了几张。拿这几项和人类表（4.1 节）对比，看规则有没有生效。

### 5.5 怎么验证

同一批开发种子跑三组：对照、`core_w=1`、`core_w=2`。看：
1. 第二幕 Boss 前有核心的比例（人类赢家 31%，我们现在 8%）——规则有没有生效；
2. 过第一幕率不能掉（v17a 的教训）；
3. 第二幕普通战每场掉血、过第二幕率。
按 4.3 节的分解，**就算牌组完全变成人类赢家那样，第二幕普通战也只能少掉约 1 血 / 场（牌本身）**；想看到大的改善，还要同时解决精英数（遗物）和战斗打法。

## 六、局限

- 都是关联。调整只控制了可观察的变量（精英、遗物、升级、张数、血量、Boss），控制不了「玩家水平」：会拿无惧疼痛的人可能也更会打。拿取率差（Δlogit）反映的是赢家的偏好，不保证照搬就有同样的效果。
- 按阶段的「拿了 vs 没拿」样本较小的格子（<100 次）只看方向，别看具体数字。
- 「有核心以后」的条件拿取率，很多格子只有 50~200 次见到，规则 3 用 ±2 封顶。
- 我们的对局只有最终牌组，没有每次奖励的选项（只有两局有记录），所以 4.2 节是「结果对比」，不是「决策对比」。
- 录像里有少量别的角色的牌（事件给的），伤害归属对能力 / 遗物伤害是按上一个事件推断的。

## 七、对已有研究的补充和修正

1. **「先引擎后终端」要改成「引擎本身就是核心」**（16、17 号第零 / 五节）：已有消耗引擎时，再有灰烬打击（56%）、契约终结（48%）不比只有引擎（60%）好。终端不是必须补的；该补的是第二个引擎（黑暗之拥）、主动消耗、战鼓。
   例外：势不可当、地狱狂徒确实要配套（没配套时 32%、21%），这和 16 号一致。
2. **战鼓不是一律的陷阱**（17 号 4.1）：第一幕前半拿确实很差（过第一幕 −16），但第二幕拿是正的（通关 +10~12），有消耗引擎时赢家的拿取率从 18% 升到 46%。
3. **契约终结在第一幕基本不要拿**（17 号把它列为终端）：第一幕拿了，过第二幕 −11~−12。
4. 规律 8「力量牌种类越多胜率越低」：这里换成核心口径后仍成立（力量多段核心调整后 −2.5~−2.9），但**恶魔形态单张对知识恶魔、无厌沙虫是正的**（+10.4、+7.0）。
