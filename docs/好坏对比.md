# 好坏一起比：我们 vs 人类赢家 vs 人类输家（每个遭遇）

> 人类 = 社区 v0.111.0 铁甲 A10 10813 局（赢 2220 / 输 8593，10/4 全量备份）；我们 = 新引擎推演 + 推演修三处的两个对照（新种子 100 局 it-iter-pub-1005-0032 + 开发 60 局 it-iter-pub-dev-1005-0034）。
> 「位置」= (我们 − 人类赢家) / (人类输家 − 人类赢家)：0 = 和赢家一样，1 = 和输家一样，**> 1 = 比输家还差**。
> 「输家死」= 人类输家里死在这场的比例。重跑：`python3 tools/goodbad.py results/<结果>.jsonl ...`

## 结论
- **几乎每一场我们都比人类输家掉血还多**（位置 > 1），不只是 Boss：普通战虔诚雕塑师 21 血（赢家 7、输家 12.5）、缩小甲虫 9.4（4.6 / 5.4）、虱子母体 19.9（9.7 / 15）。
- 按「比赢家多掉的血 × 场数」排，最该先修的：**无厌沙虫、帝皇蟹、幽灵园丁、知识恶魔、族母、骇鳗、往昔雕像、虔诚雕塑师、Kin**。
- 帝皇蟹我们死 78%（人类输家里死在这的 43%）、沙虫 48%（28%）。
- 注意：人类牌组和我们不同（同一层我们的牌组可能更弱），但 claude-value 同牌组实测也是我们掉血约人类两倍——**根子在战斗打法**。
